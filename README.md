# ✅ TaskWhiz – iOS App

**TaskWhiz** is an iOS **to‑do list app** powered by **Firebase**, built to explore modern **SwiftUI + ViewModel architecture** and cloud‑backed task management.

---

## ✨ Features

- **🔐 Firebase Authentication** – Email/password **register, login, and logout** with secure Firebase‑backed sessions. 
- **📝 Create Tasks** – Add new to‑dos with title in a clean SwiftUI form.
- **✅ Mark as Complete** – Toggle tasks as done with an intuitive check.
- **🗑️ Delete Tasks** – Remove tasks from your list via swipe‑to‑delete action. 
- **☁️ Realtime Sync with Firebase** – Tasks are stored in Firestore so changes are synced across devices.
- **📲 Reactive UI** – Task list automatically updates when data changes through ViewModel and observable state.

---

## 🛠️ Tech Stack

- **Swift** – Primary language for app logic and data layer. 
- **SwiftUI** – Declarative UI for building all screens (auth, list, add/edit views).
- **MVVM Architecture** – Separation of concerns between UI (Views) and logic (ViewModels).
- **Firebase Authentication** – Email/password auth, user management, and session handling.
- **Firebase Firestore** – Cloud NoSQL database for storing user‑specific tasks. 
- **Combine / ObservableObject** – Reactive bindings between ViewModels and SwiftUI views.
